# 블러드패스 — 확인할 것 (공식 시트 · 레코드 시트 · 표 PDF 로 알 수 없는 것)

- **조사 판정**: 낸 카드 1장의 숫자 + 그 카드 모양에 대응하는 능력치 (인간 기 = ♠, 정 = ♣ / 흡혈귀 혈 = ♥, 상 = ♦). 조사력 15 이상 = 성공 (진행도 +2), 그 밖 = 실패 (+1).
  - 대응하지 않는 모양(인간이 ♥ · ♦ 를 냄)은 능력치 0 으로 가정. 그런 카드는 애초에 조사에 못 내는지 확인.
  - 조커는 A(11) + 높은 쪽 능력치로 가정.
  - 레코드 시트의 "調査力＜14 → 失敗" 는 15 미만으로 읽었다.
- **카드 패드**: Roll20 시트는 Roll20 카드 덱을 읽을 수 없어서, 낸 카드를 시트에서 다시 고르는 방식. 손패 전체를 시트에 기록할 필요가 있는지.
- **블러드패스 강도**: 1 = 시나리오 테마 설정(손패 3) · 2 = 턴 테마 1 달성(손패 4, 혈위 1) · 3 = 턴 테마 2 달성(손패 5, 혈위 2 · 3). 혈위 줄은 강도에 따라 흐리게 표시.
- **표**: 공식 표 PDF 의 일상표 · 교류표 · 조사표 · 턴 테마표(장소 · 분위기별 변형 포함)를 모두 넣을지, 기본 표만 넣을지.
- **용어** (일본어 → 한국어, 목업 아래 용어표 참고): 練度 → 숙련도, 流儀 → 유의, 傷号 → 상호, 血契 → 혈계, 痕印 → 흔인, 血威 → 혈위, 連血鬼 → 연혈귀, 業血鬼 → 업혈귀. 공식 한국어판이 없어 직접 옮김.

## 룰북 124~151 · 212~215쪽 (캐릭터 작성 · 특기와 혈위 · 세션 준비) 확인 — 실제 시트 제작 때 반영
- 숙련도는 1 에서 시작 (142쪽).
- 팩터 표 (150쪽) — 능력치는 두 팩터 값의 합:
  - 인간 【기】/【정】: 신념 의사 4/5 · 수인 3/6 · 괴뢰 5/4 · 금우 7/2, 직능 감자 4/5 · 전위 6/3 · 수인(狩人) 5/4 · 모지 2/7.
  - 흡혈귀 【혈】/【상】: 기원 원조 4/5 · 귀종 5/4 · 야자 6/3 · 반귀 2/7, 유의 무인 6/3 · 전귀 7/2 · 주자 3/6 · 화화 4/5.
  - 내구치 = 기 × 2 + 정 (인간) · 혈 + 20 (흡혈귀), 선제치 = 정 + 10 · 상 + 4 (144~145쪽). 샘플 특별감독관 기 8 정 10 → 26 / 20, 화려한 혈투자 혈 11 상 7 → 31 / 11 로 확인.
  → 목업의 팩터 칸을 드롭다운으로, 능력치 · 내구치 · 선제치 · 혈위 이름을 자동으로.
- 혈위 (149 · 151쪽): 시나리오에 1회. 강도 2 → 인간 「암명시」 · 흡혈귀 「절명공격」, 강도 3 → 신념 · 직능 / 기원 · 유의의 혈위.
  사용 조건: 인간은 흑 그림 카드나 흑 A, 흡혈귀는 적 그림 카드나 적 A 1장 버림 (파트너가 대신 버려도 됨). 혈위로 부수는 생명 카드는 특기로 막을 수 없음.
- 특기 (146~148쪽): 대가 「손패 n장」(아무 카드) · 「흑」 ♠♣ · 「적」 ♥♦ · 「그림 카드」 J Q K · 「A」 · 「조커」 · 「내구치 n」, 조건 「드라마 · 라운드 · 혈전 · 시나리오 n회」.
  모든 캐릭터가 「무기 공격」(공격 · 단체 · 손패 1장 · 7 이하 생명 카드 1장 파괴) 을 가진다.
- 프로필 표 (134~141쪽, 카드로 고름): 과거 (팩터별 · 무늬 + 조커), 경위 (무늬), 상실 / 결락 · 외견 · 거처 · 흔인 위치 / 형상 · 약속 · 협정 · 이름 (2·3 … A·조커 7칸).
- 세션 시작 때 손패 3장을 앞면으로 (215쪽).
