# 인세인 어빌리티 → 홈페이지 룰 데이터

데이터 시트(인세인 어빌리티)를 홈페이지 `sheet/ruledata.php?rule=insane&kind=ability` 가 칸을 자동으로 맞추는 탭 한 장으로 바꾼다.

1. 데이터 시트를 `.xlsx` 로 내려받아 `src.xlsx` 로 저장
2. `python3 build_xlsx.py src.xlsx` → `인세인_어빌리티_홈페이지.xlsx`

- `어빌리티` 탭(기본 · 공적점 · 월드 어빌리티)과 `원무현한` 탭을 한 탭에 모은다 — 넣기가 종류째 갈아 끼우기 때문.
- 타입은 구획 줄(공격 · 서포트 · 장비 어빌리티)과 월드 어빌리티 이름 뒤 `(서포트)` 에서 가져온다.
- 효과의 `해설 :` 뒤는 `해설` 열로 나눈다 → 틀의 `eff2`(`tpl/insane.json`, 서버 `skin/board/character/sheet/tpl/insane.json`).
- roll20 굴림 `[[1D6]]` 은 `1D6` 으로, 지정특기의 `《》` 는 뗀다.
- 구획 줄(공적점이 필요한 어빌리티 · 월드 이름)은 남겨 둔다 — 넣기가 묶음 이름(`_grp`)으로 써서 룰 데이터 찾기에 함께 보인다.
- `월드 어빌리티` 탭은 `어빌리티` 탭 아래쪽과 같은 내용이라 쓰지 않는다. `습득조건` 열은 틀에 칸이 없어 넣지 않는다.
