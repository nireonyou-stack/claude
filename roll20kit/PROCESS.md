# 사이코로 픽션 룰 Roll20 시트 — 만드는 순서 · 노하우

블러드문 · 둘이서 수사 · 아마데우스 · 시노비가미 한국어 시트를 만들며 정한 순서. 다음 룰(인세인 · 마기카로기아 · 키루토 등)도 이대로 간다.
기술 함정(채팅 카드 CSS · Roll20 기본 CSS · 워커)은 [LESSONS.md](LESSONS.md), 이 문서는 **진행 순서와 판단 기준**.

## 1. 진행 순서 (사용자와 합의한 방식)

1. **자료 모으기** — 공식 한국어판(TRPG Club)과 일본 공식(冒険企画局 bouken.jp · 富士見 등) 캐릭터 시트 PDF.
   - 받은 파일은 스크래치패드의 새 폴더에. PDF 는 `python3.13 -I` + pymupdf 로 그림 · 글 뽑기 (poppler 는 한글 · 일본어 글꼴 없음).
   - 글자가 없는 그림 PDF 가 많다 (한국어판 닌자 · 일반인 시트, 플레이 요약본) → 확대 그림을 보고 옮긴다.
   - 유파북 등 세로판 시트가 있으면 그것이 Roll20 (830px 세로)에 맞는 배치 기준.
2. **기존 Roll20 시트 확인** — `Roll20/roll20-character-sheets` 에 같은 룰 시트가 있으면 칸(속성) 이름을 뽑아 둔다.
   - 포크 클론(`/home/user/blood-moon-korean-`, blob:none)에서 `git show upstream/master:<폴더>/<파일>` 로 받는다 (sparse-checkout 은 건드리지 않음).
   - 같은 이름을 쓰면 홈페이지 짝표 · 올인원 자동완성 · 시트 바꾸기(옛 캐릭터 이어 쓰기)가 함께 맞는다. 바꿀 수밖에 없는 것은 **만들기 전에** 사용자에게 알린다.
3. **요구사항 정리** — 공식 시트의 칸 목록 · 시트 종류(PC · 일반인 · GM용 등) · 굴림 · 채팅 카드.
4. **목업** (`<룰>/roll20/mockup.html` → Artifact) — 세로 830px 시트 + 채팅 카드 예시. 값은 예시임을 적는다.
5. **계획 → 사용자 승인 → 만들기** (`src/*.src.html` + `build.py` + `worker.js` + `rolltemplate.html` → `sheet/`).
6. **검사** — `python3 roll20kit/lint.py <sheet 폴더>` 0/0 · `node test/test.js` (r20sim) · `node roll20kit/view.js` 가상 Roll20 화면 + 채팅 카드를 그림으로 확인.
7. **제출** — 폴더 이름 · 제작자 · 브랜치 · PR · 배포 확인은 [SUBMIT.md](SUBMIT.md).

## 2. 시트에 넣는 것 · 안 넣는 것

> **원칙 (사용자 결정 2026-11-23)**: 공개된 공식 캐릭터 시트 · 레코드 시트 · 서머리에 있는 것만 구현한다. 룰북에만 있는 규칙 · 표 · 자동 계산은 새로 넣지 않는다 (DOC 표, 팩터 계산, 심플 혈전 등은 손으로). 이미 제출한 시트는 그대로 둔다.

- 시트의 글은 **공식 시트에 인쇄된 글만** (칸 이름 · 인쇄된 규칙 요약 · 인쇄된 아이템 효과 등). 룰북 문장(유파 목적 · 오의 기본 효과 등)은 넣지 않는다.
- 미리 채운 값 · 예시 · placeholder · 괄호 설명 · AI 같은 보조 라벨 없음.
- 이모지 없음 → 단추는 CSS 로 그린 아이콘: 주사위(굴림) · 말풍선(채팅에 출력만). `currentColor` 로 그려 색은 글자색을 따른다.
- 출판사 로고 · 삽화 · 유파 문장 그림 없음 (Roll20 체크리스트 + bouken.jp 이용 규약 = 재배포 금지). 제목은 웹 글꼴로 쓴 글자.
- 다른 사람이 만든 커스텀 시트는 사용자가 허락한 범위에서 기능만 참고하고, 코드는 새로 쓴다.
- 색: 흰 종이 · 검은 띠 · 무채색 (베이지 안 씀). 강조색은 룰의 상징색 하나 정도.

## 3. 사이코로 픽션 공통 부품

- **특기 리스트** (6분야 × 2~12): 칸 = 습득 표시 · 이름 단추(누르면 판정) · 목표치. 분야 사이 공백 칸은 열 전체를 덮는 막대 하나(체크칸)로.
  - 목표치 = 5 + 거리 (세로 한 칸 1, 옆 분야 2, 칠한 공백을 건너면 1, 최대 12). 블러드문 `worker.js` 의 `distance` 를 다시 쓴다.
  - 2D6 합 2 는 늘 펌블, 12 는 늘 스페셜. 스페셜치 · 펌블치가 바뀌는 효과(전투 중 플롯치 등)는 자동으로 찍지 않는다 (블러드문 5a5d65a).
- **인물 칸 · 감정** (+/−), **【비밀】 · 오의 · 진실처럼 숨겨야 하는 칸**:
  Roll20 은 시트를 편집 권한이 있는 사람에게만 보여 주므로, 공개 시트 = 모두가 편집 가능 → 시트 일부만 숨길 수 없다.
  - 시노비가미는 공식 시트의 "접는 곳"처럼 **접는 칸**(누구나 펼 수 있는 가림막)으로 합의. 시트를 열 때 접힌 상태로 돌린다.
  - 진짜로 숨기려면 별도 캐릭터(권한을 본인 + GM 만) — 사용자에게 두 방식을 함께 제시했었다.
- **시트 종류**(닌자 / 일반인 · 탐정 / 조수 등)는 드롭다운 하나, 이름은 공식 시트 제목 그대로("닌자용 캐릭터 시트").
- 인쇄된 기본 줄(접근전 공격 · 기본 액션 등)은 입력칸이 아니라 시트에 인쇄된 글로.

## 4. 함께 맞춰야 하는 곳

- 홈페이지 짝표 `homepage/sheet/import.roll20.lib.php` — 룰별 `r20i_map_<룰>` · `r20i_detect`. 시트 칸 이름을 바꾸면 여기도.
- 올인원 자동완성 `userscript/roll20-layout2-allinone.user.js` 의 `autofill` (`FIELDS` · `NAME_RE` · 룰 알아보기). 반복 줄 칸 이름과 고르기 글자로 채운다.
- 시트마다 `<룰>/roll20/FIELDS.md` (짝표용 칸 목록 · 값 모양).

## 5. 사용자 선호 (대화에서 정해진 것)

- 한국어로, 짧게. 큰 일은 요구사항 → 목업 → 계획 → 승인 → 코드.
- 슬림한 화면. 공식 시트 배치를 최대한 따른다.
- **남는 여백이 보이지 않게 꽉 채운다** — 같은 줄의 칸끼리 높이가 다르면 짧은 칸의 줄 · 입력칸을 늘려 맞춘다 (2026-11-22, 목업 네 개 모두 적용).
- 공식 한국어판이 없는 게임은 사용자가 준 한국어 시트 · 용어집을 따른다 (예: 사무라이 블레이드 = TR꿈악어 님 한국어 시트, 특기 1~2 글자). 없으면 일본어 원문을 옮기고 목업의 용어표로 검토받는다.
- 유저스크립트를 올리면 커밋 해시가 든 raw GitHub 주소를 준다.
