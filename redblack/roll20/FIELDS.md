# 적과 흑 (Korean) — 칸 이름

홈페이지 짝표 · 올인원 자동완성이 쓰는 속성 목록. Roll20 에 같은 룰 시트가 없어 새로 정한 이름이다.

| 속성 | 뜻 | 값 |
|---|---|---|
| `lineage` · `character_name` · `rank` | 계보 · 이름·칭호 · 작위 | 글 · `영주` / `추기경` / 빈칸 |
| `gender_age` · `disguise` · `origin` · `principle` | 성별·나이 · 위장·파벌 · 출신 · 원리 | 글 |
| `ms1` · `ms2` · `ms3` · `detail` | 마법 체계 · 상세 정보 | 글 |
| `logic` · `magic` | 로직 · 매직 | 숫자 |
| `hp_init` · `hp_restore` · `mb_init` · `mr_init` | HP 초기치 · 복원치 · 흑의 마력 · 적의 마력 초기치 | 숫자 |
| `hp` · `mb` · `mr` · `glory` | 사건 보고서 줄: 현재 HP · 흑의 마력 · 적의 마력 · 영광 | 숫자 (영광 기본 5) |
| `pc1`~`pc10` | 낸 카드 (색 b 흑 · r 적 + a 2~10 j q k, 광대 `jx`, 워커가 씀) | 예 `b7` · `rq` · `jx` / 빈칸 |
| `pc1_k` · `pc1_s` … | 칩 표시 글자 · 무늬 (워커가 씀) | 글 |
| `sum_b` · `sum_r` · `sum_n` | 낸 카드 흑 합계 · 적 합계 · 장수 (그림 10 · A 15 · 광대 15, 광대는 두 합계에 모두) | 숫자 |
| `acc_power` · `acc_count` | 고발 공격 위력 · 횟수 | 숫자 |
| `attack` · `shield` · `break` · `revenge` | 키워드 효과 〈어택〉 · 〈실드〉 · 〈브레이크〉 · 〈리벤지〉 (살해되면 워커가 비움) | 숫자 |
| `killed` | 살해됨 (워커가 피해 · 복원 때 씀) | `1` / `0` |
| `crest1`~`crest3` `_name` · `_on` · `_desc` · `_text` | 문장 이름 · 해금 · 묘사 · 효과 | 글 · `1` |
| `bc1`~`bc6` `_name` · `_boot` · `_lv` · `_text` | 기본 선언 (〔기동〕 예 `흑：12`, `？：10`, `—` = 기동 불가) | 글 |
| `nc1`~`nc6` `_name` · `_boot` · `_lv` · `_text` | 상급 선언 | 글 |
| `au1`~`au9` `_name` · `_boot` · `_black` · `_red` · `_text` · `_acc` · `_sup` | 권한 마법 (〔마력〕 조건 흑 · 적, 고발 · 원호) | 글 · `1` (`－` = 조건 없음) |
| `roll_display_to` | 공개 범위 | `" "` 모두에게 · `"/w gm "` GM 에게 |
