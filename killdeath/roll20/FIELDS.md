# 킬데스 비즈니스 (Korean) — 칸 이름

홈페이지 짝표 · 올인원 자동완성이 쓰는 속성 목록. Roll20 에 같은 룰 시트가 없어 새로 정한 이름이다.

| 속성 | 뜻 | 값 |
|---|---|---|
| `sheet_type` | 시트 종류 | `pc` 회수인 · `tg` 표적/호위천사 |
| `character_name` · `player` · `gender` · `age` | 이름 · 플레이어 · 성별 · 나이 | 글 |
| `wish` | 소원 | 글 (여러 줄) |
| `char_attr` | 캐릭터 속성 (회수인) | 글 |
| `strength` | 강함 (표적) | 글 |
| `battle_style` | 전투 스타일 | 글 |
| `A2` … `F12` | 특기 습득 (열 A~F = 직업 · 동작 · 소품 · 의상 · 정동 · 소망, 줄 2~12) | `1` / 빈칸 |
| `A2_value` … | 목표치 (워커가 계산) | 숫자 / 빈칸 |
| `gap_a` … `gap_e` | 공백 칠하기 (a = 직업 \| 동작 … e = 정동 \| 소망) | `1` / 빈칸 |
| `ab7_name` · `ab7_effect` · `ab7_skill` | 리스크 7 (킬러 트릭, 레벨 없음) | 글 |
| `ab1`~`ab6` `_name` · `_level` · `_effect` · `_skill` | 리스크 1~6 어빌리티 | 글 (지정특기는 《》 있어도 됨) |
| `rel1`~`rel6` `_used` · `_name` · `_attr` · `_depth` | 관계 (사용함 · 이름 · 속성 · 심도) | `1` / 글 / 숫자 |
| `cy1`~`cy5` `_name` · `_effect` | 헬 사이버 (회수인) | 글 |
| `sub_name` · `sub_clear` · `sub_reward` | 서브플롯 (회수인) | 글 |
| `charge` · `block` | 차지 · 블록 | 0~3 |
| `deaths` | 사망 횟수 (회수인) | 0~6 |
| `soul` · `hell_slug` | 소울 · 헬 슬러그 (회수인) | 숫자 · 글 |
| `life` | 라이프 (표적) | 숫자 |
| `memo` | 메모 | 글 |
| `mod` | 다음 판정 수정치 | 숫자 |
| `fumble_adj` · `special_adj` | 펌블치 · 스페셜치 손 수정 | 숫자 |
| `fumble` · `special` | 펌블치 · 스페셜치 (워커가 계산, 기본 2 · 12) | 숫자 |
| `roll_display_to` | 공개 범위 | `" "` 모두에게 · `"/w gm "` GM 에게 |

공격 판정(어빌리티 주사위)의 펌블치는 그 어빌리티의 리스크 + `fumble_adj` (룰북 확인, 2026-11-22).
