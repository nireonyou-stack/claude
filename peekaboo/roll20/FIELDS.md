# 피카부 (Korean) — 칸 이름

홈페이지 짝표 · 올인원 자동완성이 쓰는 속성 목록. Roll20 에 같은 룰 시트가 없어 새로 정한 이름이다.

| 속성 | 뜻 | 값 |
|---|---|---|
| `sheet_type` | 시트 종류 | `in` 이노센트용 · `sp` 스푸키용 |
| `character_name` · `player` · `weakness` | 이름 · 플레이어 · 약점 (두 데이터 공통) | 글 |
| `age` · `gender` · `setting` · `talent` | 나이 · 성별 · 설정 · 재능 (이노센트) | 글 |
| `talent_used` | 재능 사용 □ (이노센트) | 0~6 |
| `muka` | 부글부글 포인트 □ | 0~10 (스푸키 칸은 5개) |
| `ring` · `attack` · `defense` · `help` · `hinder` | 링(~족) · 공격력 · 방어력 · 도움력 · 방해력 (스푸키) | 글 · 숫자 |
| `mp` | 마력 = 마력 슬롯 (스푸키) | 0~30 |
| `A2` … `F12` | 특기 습득 (열 A~F = 불량 · 운동 · 친구 · 놀이 · 공부 · 어른, 줄 2~12) | `1` / 빈칸 |
| `A2_value` … | 목표치 (워커가 계산) | 숫자 / 빈칸 |
| `gap_a` … `gap_e` | 공백 칠하기 (a = 불량 \| 운동 … e = 공부 \| 어른) | `1` / 빈칸 |
| `slot_a` … `slot_f` | 원기 슬롯 (체크한 분야의 습득 특기는 목표치 출발점에서 빠짐) | `1` / 빈칸 |
| `sleep` | 졸음 (이노센트) | 0~30 |
| `sleep_mod` · `sleep_band` | 졸음 수정치 · 단계 (워커가 계산) | 0 / -1 / -2 · 0~6 |
| `adventure` · `money` | 모험의 기록 · 용돈 (이노센트) | 글 |
| `ob1`~`ob5` `_name` · `_weak` | 만난 적 있는 오바케 · 약점 | 글 |
| `xp_in` · `xp_sp` | 이노센트 · 스푸키의 경험치 | 글 |
| `body_*` · `cos1_*` · `cos2_*` `_name` · `_effect` | 몸 · 의상 1 · 의상 2 (스푸키) | 글 |
| `mg1`~`mg3` `_name` · `_cost` · `_effect` | 마법 (말풍선 = 마력에서 코스트를 빼고 채팅) | 글 · 숫자 |
| `mod` | 다음 판정 수정치 | 숫자 |
| `fumble_adj` · `special_adj` | 펌블치 · 스페셜치 손 수정 | 숫자 |
| `fumble` · `special` | 펌블치 · 스페셜치 (워커가 계산, 기본 2 · 12) | 숫자 |
| `roll_display_to` | 공개 범위 | `" "` 모두에게 · `"/w gm "` GM 에게 |
