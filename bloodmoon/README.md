# 블러드문 기본룰북 → 플레이어 시트 · 홈페이지 룰 데이터

번역 룰북(Google Docs)의 어빌리티/아이템 카드를 플레이어 시트의 `어빌리티`·`아이템` 탭과 같은 열 구성으로 변환한다.
결과 탭은 홈페이지 `sheet/ruledata.php`(룰 데이터 넣기)가 머리줄로 칸을 자동으로 맞출 수 있는 꼴이다.

1. 룰북을 Google Docs에서 `.txt`로 내려받아 CRLF를 제거해 `d.txt`로 저장
2. `python3 parse.py` → `parsed.json`
3. (서플리먼트) `python3 extract_gw.py <기존 플레이어 시트.xlsx>` → `gw.json` — 길티 위치즈 어빌리티 72 · 레어아이템 4
4. `python3 build_xlsx.py` → `블러드문_기본룰북_데이터.xlsx`

- 표 셀은 텍스트 내보내기에서 탭으로 시작하는 줄로 구분된다는 점을 이용해 파싱한다.
- 역주 각주(`[80]` 등)는 본문에서 제거하고 `비고` 열로 옮긴다.
- 이름은 `원어⏎이름` 두 줄 — 홈페이지 넣기가 마지막 줄을 이름, 앞줄을 원어(ruby)로 나눈다.
- `룰북` 열(기본룰북 · 길티 위치즈)은 룰 데이터 찾기의 룰북 거르기가 된다.
- 룰 데이터 넣기는 그 종류를 통째로 갈아 끼우므로 서플리먼트도 같은 탭에 둔다.
- `개요`(플레이버)는 어빌리티 줄의 둘째 줄(`eff2: desc`)로 들어간다 — 서버 `skin/board/character/sheet/tpl/bloodmoon.json` 을 `tpl/bloodmoon.json` 으로 바꿔 올린다.
- `레벨제한` · `비고` 열은 틀에 칸이 없어 넣지 않는다.
