# 사무라이 블레이드 (Korean) — 칸 이름

홈페이지 짝표 · 올인원 자동완성이 쓰는 속성 목록. Roll20 에 같은 룰 시트가 없어 새로 정한 이름이다. 용어는 TR꿈악어 님 한국어 캐릭터 시트를 따른다.

| 속성 | 뜻 | 값 |
|---|---|---|
| `character_name` · `gender` · `age` · `player` · `created` | 이름 · 성별 · 연령 · 플레이어 명 · PC 작성일 | 글 |
| `konpaku` · `level` · `main_school` · `sub_school` | 혼백 · 레벨 · 주류파 · 부류파 | 글 |
| `career` · `career_skill` · `job` · `origin` · `origin_skill` | 경력(+특기) · 직업 · 출신(+특기) | 글 |
| `awaken` · `awaken_skill` · `blade_name` · `incarnation` | 각성(目覚め, +특기) · 무령도 이름 · 화신 | 글 |
| `hp` · `hp_base` · `hp_equip` · `hp_max` | 생명력 현재 · 기본치 · 장비품 · 총합(워커가 계산) | 숫자 |
| `awakened` | 【각성】 상태 (판정 부스트 +1) | `1` / 빈칸 |
| `merit` | 공적점 | 글 |
| `A2` … `F12` | 특기 습득 (열 A~F = 재능 · 숙달 · 이지 · 신체 · 감성 · 심연, 줄 2~12) | `1` / 빈칸 |
| `A2_value` … | 기본 목표치 (워커가 계산, 난이도 전) | 숫자 / 빈칸 |
| `dif` · `boost` · `mod` | 난이도 (0 · 5 · 10 · 15) · 부스트 · 수정치 | 숫자 |
| `pab1`~`pab4` `_used` | 인쇄된 어빌리티 사용함 | `1` / 빈칸 |
| `mr_skill` · `mr_dmg` | † 무령도 기능 · 이동공격 대미지 | 글 · 숫자 |
| `ab2`~`ab7` `_name` · `_cond` · `_timing` · `_skill` · `_range` · `_target` · `_count` · `_effect` | 어빌리티 레벨 2~7 | 글 (기능은 《》 있어도 됨) |
| `ab2`~`ab7` `_u1` · `_u2` · `_u3` | 사용함 | `1` / 빈칸 |
| `mis1` · `life` · `mis3` · `mis4` · `mis1_done` … `mis4_done` | 사명 · 삶 · 달성 | 글 · `1` |
| `en1`~`en6` `_name` · `_emo` · `_bond` | 인연 · 감정 · 유대 | 글 · `1` |
| `gs1`~`gs6` · `bs1`~`bs6` | GS (고양 · 축복 · 가속 · 철벽 · 신격 · 무쌍) · BS (맹독 · 주박 · 발묶임 · 공포 · 부상 · 혼란) | `1` / 빈칸 |
| `eq1`~`eq5` `_name` · `_type` · `_range` | 장비품 (무기 · 보조무기 · 방어구 · 보조방어구 · 장식품) | 글 |
| `it1`~`it6` `_n` | 아이템 개수 (방진 · 병기 · 영측 · 약품 · 탈것 · 호부) | 0~3 |
| `fumble_adj` · `special_adj` · `fumble` · `special` | 펌블치 · 스페셜치 손 수정 · 값(워커가 계산) | 숫자 |
| `roll_display_to` | 공개 범위 | `" "` 모두에게 · `"/w gm "` GM 에게 |
