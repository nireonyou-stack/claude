# 올인원 개발지침

대상: `roll20-layout2-allinone.user.js` — Roll20 GM용 올인원 유저스크립트.
사람과 Claude 모두 이 문서를 따른다. 지침을 바꿀 때는 이 문서부터 고친다.

## 0. 진행 방식

- 큰 작업은 **요구사항 → 목업(그림) → 계획 → 승인 → 코드** 순서. 승인 전에는 코드를 쓰지 않는다.
- 화면이 바뀌는 일은 목업으로 먼저 합의한다.
- 확실하지 않으면 추측해서 만들지 말고 필요한 것만 묻는다.
- 기존 코드를 존중한다. 불필요한 리팩터링 금지. 새 기능 전에 다시 쓸 수 있는 코드부터 찾는다.
- 버그는 최소 수정. 잘 되는 곳은 건드리지 않는다.
- 검증된 오픈소스가 있으면 직접 만들기 전에 먼저 제안한다 (유지보수 상태 · 의존성 확인).
- 설명은 짧게, 결론과 필요한 코드만.

### 1-2. UX/UI 개선

아래 '4. UX 규칙'의 다섯 원칙에 맞춰 기존 화면을 하나씩 고친다. 화면이 바뀌는 일이라 목업으로 먼저 합의한다.
순서: 1-1 → 1-2. 창 틀과 알림은 1-1에서 만든 공용 부품 위에 짓는다.

## 2. 코드 구조

- 기능 하나 = FEAT 모듈 (`inject` · `setEnabled` · `watch`). 묶음은 `addBundle`.
- 새 창은 `AIO_ZOOMED`에 넣는다 (글자 크기 확대가 먹게).
- 공용 함수를 먼저 쓴다: `aioToast`(알림) · `el` · `escAttr` · `copyText` · `r20img` · `sizedUrl` · `grpDrop` · `tblHead` · `tblSections` · `aioErr` · `btnVisible`.
- 이름 앞머리: 기능별 `r20xx-`, 공용 부품은 `aio-`.
- 저장 키: `localStorage` `r20_<기능>_<항목>`. 읽기 · 쓰기는 try/catch.
- 방 데이터(핸드아웃 · 매크로 · 굴림표)에 쓸 때는 저장 버튼을 거치고, 저장 전에는 되돌릴 수 있게.
- 주석은 한국어로 짧게. '무엇'보다 '왜'.

## 3. CSS 규칙

- 색 · 글자 크기 · 높이 · 모서리 · 겹침 층 · 그림자는 `--aio-*` 변수만 쓴다. 새 hex 금지.
  - 글자: `--aio-fs-xs/sm/md/lg/xl` (10 · 11 · 12 · 13 · 15px). 예외는 아이콘 글리프 8 · 9px, 큰 숫자 · 이모지 20 · 21px.
  - 강조색을 옅게 쓸 때는 `color-mix(in srgb, var(--aio-accent) n%, transparent)` — 강조색을 바꾸면 같이 바뀐다.
  - 그림자: `--aio-shadow-sm`(작은 것) · `-md`(펼침 · 메뉴) · `-lg`(창 · 알림). inset 등 특수한 것만 직접.
  - 겹침 층: `--aio-z-dock` < `-win` < `-pop` < `-tip` < `-toast`, 같은 층 안 순서는 `calc(var(--aio-z-win) + n)`. 창 안에서만 쓰는 1~20 은 숫자.
- `!important`는 Roll20 요소 · Roll20 스타일을 덮어써야 할 때만, 이유를 주석으로. 올인원이 만든 요소에는 새로 쓰지 않는다 (우선순위는 선택자로).
- 값이 바뀔 수 있는 CSS 정리는 `node tests/style-snap.js 옛판 새판` 으로 올인원 창 안 계산된 모양을 견준다 ('다른 요소 0개').
- 공용 부품(`aio-`)이 있으면 그것을 쓰고, 없으면 공용으로 만든다.
- 14인치 노트북 기준으로 슬림하게. 좁은 폭에서도 가로 넘침 없게.
- 크기 조절 손잡이는 아이콘(↔)만. 색 막대 금지.
- Blood Moon 시트 CSS는 ASCII만.

## 4. UX 규칙 — 새 기능 · 고치는 기능 모두 늘 지킨다

다섯 원칙:

1. **창 틀은 하나**: 모든 창이 같은 머리줄 순서 **⠿ 끌기 · 제목 · (창마다 동작) · 자리 · 📌 · ✕**, 같은 끌기(`aioDrag`), 같은 자리 고르기(`aioDockSeg` — 붙임 · ½ · 떠 있기 중 그 창이 되는 것만)를 쓴다. 찾기 칸은 머리줄 아랫줄. 새 창도 이 틀로 만든다.
   - 틀을 안 쓰는 것: 단추 옆에 잠깐 뜨는 **펼침 창**(포트레이트 권한 · 이모지 · 묶음 드롭다운 등 — 바깥 누르면 닫힘)과 **모달**(시트 촬영). 이것들도 제목 · ✕ 순서와 Esc 닫기는 지킨다.
2. **알림은 하나**: 저장 · 복사 · 실패는 공용 알림으로 알린다. 되돌리기 어려운 동작에는 알림에 [되돌리기]를 준다.
3. **키보드 하나로**: 모든 기능을 빠른 찾기(Ctrl+F) 창에서 명령으로도 실행할 수 있게 등록한다. 단축키가 있으면 툴팁에 함께 적는다.
4. **설정은 쓰임새대로**: 새 설정은 쓰임새(세션 진행 / 준비 / 화면) 아래에 두고 설정 찾기에 걸리게 한다.
5. **누구나 읽고 쓸 수 있게**: 글자 대비 4.5:1 이상, '움직임 줄이기' 대응, 키보드 포커스가 보이게.

그 밖에:

- Esc 닫기, ↑↓ Enter 고르기. 입력칸에서는 Roll20 단축키가 먹지 않게 (`stopPropagation`).
- 아이콘 단추에는 `aria-label`과 툴팁.
- 사용자가 고른 것은 기억한다 (창 위치 · 크기 · 고른 묶음 등).
- 실패는 조용히 숨기지 않고 보이게 표시한다 (예: 안 열리는 그림 → "그림 안 열림" 칸).
  숨기면 사용자는 기능이 고장 난 줄 안다.
- 되돌리기 어려운 동작은 확인을 받거나 되돌리기를 준다.

## 5. 성능

- MutationObserver는 좁은 범위만, 몰아서 처리.
- 그림은 `loading="lazy"`, 썸네일 우선.
- 큰 목록은 보일 때만 그린다.

## 6. 검증 · 배포

- `node --check` → `bash tests/run.sh` (테스트 묶음 전부 · 이름을 주면 그것만). checktest의 bad=3은 의도된 것.
- 새 기능 · 고친 버그마다 `tests/`에 테스트를 더하고 `run.sh` 목록에 넣는다.
- 화면이 바뀌면 Playwright 스크린샷으로 직접 확인한다.
- 실제 Roll20에서 못 해 본 것은 그렇다고 말한다.
- 버전: `@version`과 `SCRIPT_VER`를 같이 올린다. 기능 추가 = 가운데 자리, 고침 = 끝자리.
- 파일이 1MB가 넘어 Claude 앱 미리보기 · 내려받기가 잘린다 → 사용자에게는 **zip**으로 준다.
- 테스트는 Playwright(실행 환경에 깔린 것) + 정적 서버 `tests/serve.js`(127.0.0.1:8766). jQuery · Summernote 등은 `tests/package.json`의 npm 패키지.

## 7. 지켜야 할 것

- 쥬나 아틀리에: 유료 디자인 · 비밀번호 재배포 금지, 출처 "쥬나 아틀리에" 유지.
- 배포판: `// @share-cut-start … // @share-cut-end` 구간은 배포판에서 뺀다 (배포 빌드는 보류 중).
- 사용자 정보(이름 · 메일 등)를 외부 서비스로 보내지 않는다.
